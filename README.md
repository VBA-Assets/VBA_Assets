# VBAアセット ソースコード

[VBAアセット](https://vba-assets.net/)で公開している、Word・Excel のアドイン（VBA）のソースコードです。

- ライセンス：MIT License（[LICENSE](LICENSE)）。改変・再配布・商用利用ができます。
- アドイン本体（dotm・xlam・xlsm）とインストーラーは、[VBAアセット](https://vba-assets.net/)の各記事からダウンロードしてください。
- 各フォルダには、VBE から書き出したモジュール（.bas・.cls・.frm）と、モジュールの一覧（manifest.json）を置いています。文字コードは UTF-8（BOMなし）、改行は CRLF です。
- アドインの版を上げるたびに、このリポジトリも更新します。
